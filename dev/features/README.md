# Features

- [Drainage exploration](drainage-exploration.md): review-only stream snapping,
  HUC12/basin candidates and bounded network navigation for human scope decisions.

- [Terrain clipping](terrain-clipping.md): execute explicit AOI crop/mask with
  automatic run evidence, source preservation and a short visual report.

- [Terrain preparation accounts](terrain-processing-accounts.md): ordered,
  attributed preparation descriptions with explicit unknowns; no inferred execution.

- [Retained terrain evidence](retained-terrain-evidence.md): preserve selected
  supporting files and review their integrity without promoting source claims.

- [Terrain source-use evidence](terrain-source-use.md): attributed candidate/use/
  rejection records bound to inventoried terrain fingerprints, shared by reports.

- [Report table readability](report-table-readability.md): shared responsive
  presentation for early-workflow HTML reports without changing scientific data.

Describe cohesive user-visible or cross-cutting capabilities here when their behavior spans more than one implementation file. Link to authoritative decisions and schemas instead of duplicating them.

- [Offline survey-opportunity report](survey-opportunity-report.md): single-study,
  multi-catalog discovery review with explicit event history and evidence limits.
- [Vertical-reference observation](../schemas/vertical-reference-observation.md):
  read-only recovery support; distinguishes ordinary reader exposure from embedded
  compound CRS without assigning metadata or changing existing intake records.
- [Terrain reference review](../schemas/terrain-reference-review.md): optional
  report evidence separating source/analysis declarations, chosen project references
  and preparation history, with grouped next questions and collapsible definitions.
- [Saved analysis-reference choices](../schemas/study-context.md#attributed-analysis-choices-development-9014):
  explicit attributed project choices, preserved in new context snapshots and
  reused in reports; not file metadata, executed transformations or approval.
